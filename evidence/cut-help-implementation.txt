vidcapture — CLI screen and audio recorder for macOS

USAGE:
    vidcapture <COMMAND> [FLAGS]
    vidcapture -h | --help    Show short flag help (auto-generated by clap)

COMMANDS:
    start    Start capturing screen and audio
    cut      Cut a range out of an existing video file
    help     Show this help message with setup instructions

FLAGS (start):
    -d, --duration <TIME>    Capture duration. Stops automatically after this time.
                             Examples: 10s, 2m, 1h, 1h30m10s
    -e, --every <TIME>       Interval mode. Split the capture into segments of this duration.
                             Examples: 10s, 2m
                             Each segment is a standalone, playable MP4.
    -o, --output <DIR>       Output directory for the recorded file(s).
                             Default: current working directory.
                             Example: ./recordings/
                             Created if it does not exist. Filenames auto-increment on collision.
    -v, --verbose            Show ffmpeg output while recording.

FLAGS (cut):
    <SOURCE>                 Path to the source video file. Required.
    -f, --from <TIME>        Start offset of the cut range (default: 0s).
    -t, --to <TIME>          End offset of the cut range. Conflicts with --length.
    -l, --length <TIME>      Cut length. Conflicts with --to.
    -o, --output <PATH>      Output file or directory.
        --fast               Stream-copy instead of re-encoding.
    -v, --verbose            Show ffmpeg output.
                             Requires ffmpeg but not BlackHole.

DURATION FORMAT:
    A timespec is one of two notations:

    Unit-suffixed: a sequence of <number><unit> pairs.
        Units: h (hours), m (minutes), s (seconds), ms (milliseconds).
        Decimals are allowed: 1.5s = 1500ms, 0.25m = 15s.
        Examples:
            10s         10 seconds
            1500ms      1.5 seconds
            1.5s        1.5 seconds
            2m          2 minutes
            1h          1 hour
            1h30m       1 hour 30 minutes
            1h30m10s    1 hour 30 minutes 10 seconds

    Timestamp: HH:MM:SS[.mmm] or MM:SS[.mmm].
        Examples:
            00:01:30.500   1 minute 30.5 seconds
            01:30          1 minute 30 seconds
            1:02:03.250    1 hour 2 minutes 3.25 seconds

SETUP:

  1. Install ffmpeg:
       brew install ffmpeg
     Verify with: ffmpeg -version

  2. Install BlackHole 2ch (for system audio capture):
       brew install blackhole-2ch

  3. Configure Multi-Output Device in Audio MIDI Setup:
       a. Open Audio MIDI Setup (in /Applications/Utilities).
       b. Click the + button at the bottom-left and choose "Create Multi-Output Device".
       c. In the new device, check both "BlackHole 2ch" and your speakers/headphones.
       d. Right-click the Multi-Output Device and select "Use This Device For Sound Output".
       e. Set its drift correction to the BlackHole entry.

  4. Sanity check that ffmpeg sees your devices:
       ffmpeg -f avfoundation -list_devices true -i ""

EXAMPLES:
    vidcapture start                      # Record until you press 's'
    vidcapture start -d 30s               # Record for 30 seconds
    vidcapture start -e 10s               # Cut into 10-second segments
    vidcapture start -d 1m -e 10s         # 6 segments of 10 seconds, then stop
    vidcapture start -o ./recordings/     # Save into ./recordings/
    vidcapture start -v                   # Show ffmpeg output while recording
    vidcapture cut talk.mp4 --length 5s   # First 5 seconds
    vidcapture cut talk.mp4 --from 10s --to 25s  # From 10s to 25s
    vidcapture cut talk.mp4 --from 10s --length 1.5s  # 1.5s starting at 10s
